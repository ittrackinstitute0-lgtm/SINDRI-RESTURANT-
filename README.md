## 🌟 Overview
**Sindri Restaurant** is a luxury, responsive web experience dedicated to the royal culinary heritage of Pakistan. Designed with a bespoke warm cream background, deep chocolate typography, glowing caramel interactive buttons, delicate dusty pink badges, and ancient gold filigree highlights.

## ✨ Key Features & Animations
- **Aesthetic Modern Animations**: Smooth scroll reveal, floating badges, hot chai rising steam particles, button hover shines, and gold border shimmer.
- **Interactive Dastarkhwan Cart**: Live cart sliding drawer calculating item totals, 16% provincial sales tax (GST), and direct WhatsApp order forwarding.
- **Dish Quick View Modal**: In-depth ingredients breakdown, spice level meter, and chef pairing recommendations.
- **Table & Majlis Reservation**: Real-time form with guest selector, dining preferences (Floor Dastarkhwan, Private Pavilion, Grand Hall), and instant confirmation booking ID.
- **Mobile Responsive**: Fully responsive layout tailored for phones, tablets, laptops, and ultra-wide screens.
